# API

The API contract is specified in [PLAN.md, section 8](PLAN.md#8-api-specification-apiv1).

From D1 on, the live OpenAPI documentation (Swagger) is served by the backend at:

- Local: `http://localhost:3000/api/docs`
- Base path for every endpoint: `/api/v1`

This file will hold a short endpoint summary as modules are implemented.
